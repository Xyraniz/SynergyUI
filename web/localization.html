La localización es global para todas las ventanas activas. Registra diccionarios, define un fallback y utiliza claves @Key allí donde el runtime pueda volver a resolver el texto.

ConfiguraciónFormato de clave
cambio de idioma
SynergyUI:Localization({
  FallbackLanguage = "en",
  Language = "es",
  Translations = {
    es = {
      Accept = "Aceptar",
      Search = "Buscar…",
    },
  },
})

Configura las traducciones

Hay una forma declarativa para el arranque y métodos incrementales para actualizar un idioma después.

Configuración declarativa

Localization(config) acepta FallbackLanguage, Translations y Language. Locations(config) es un alias directo.

SynergyUI:Localization({
  FallbackLanguage = "en",
  Language = "es",
  Translations = {
    es = { Accept = "Aceptar", Cancel = "Cancelar" },
  },
})

Configuración incremental

AddTranslations crea el idioma si aún no existe, mezcla las claves y actualiza los objetos registrados.

SynergyUI:AddTranslations("es", {
  Search = "Buscar…",
  Selected = "seleccionados",
})
SynergyUI:SetLanguage("es")

La convención de @Key

El prefijo distingue una clave del texto literal. Solo las strings que empiezan con @ se resuelven.

Valor localizado

En un control, pasa Name = "@Accept". El runtime almacena un resolver y vuelve a calcular la propiedad cuando cambia el idioma.

Tab:CreateButton({
  Name = "@Accept",
  Callback = function() end,
})

Valor literal

Un texto sin @ nunca se busca en el diccionario. Esto permite mezclar UI traducida con nombres de producto o valores libres.

Tab:CreateLabel("SynergyUI")
Tab:CreateLabel("@Accept")
Resolución del fallbackLa resolución intenta, en orden, Translations[Language][key], Translations[FallbackLanguage][key] y finalmente devuelve el nombre de la clave sin el prefijo.

Cambia el idioma en runtime

Las ventanas existentes se actualizan en el momento. El título se vuelve a medir para evitar solapamientos con el subtítulo.

Window:SetLanguage("es")
Window:RefreshLocalization()

-- Ambas llamadas terminan en el registro global.
-- RefreshLocalization fuerza además el update del layout del título.

Controles

Las etiquetas, botones, placeholders, títulos de diálogos y textos de acción se vuelven a resolver.

Ventanas

Los títulos y subtítulos recalculan ancho disponible mediante TextService.

Limpieza

Cuando un objeto se destruye, el registro lo elimina en la siguiente pasada de actualización.
