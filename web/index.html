The mental model

La API sigue una jerarquía deliberadamente pequeña. Aprende esta secuencia y el resto se vuelve composición.

Window

El contenedor visual y el ciclo de vida: tema, tamaño, toggle key, persistencia, overlays y diálogos.

SynergyUI:CreateWindow

Tab

Una sección navegable. Cada tab devuelve el objeto elements, que concentra todos los constructores.

Window:CreateTab

Element

Un control con opciones, flag, valor inicial y callback. Las flags permiten leer y cambiar estado desde fuera.

elements:Create*

Regla práctica: define un Flag estable para cada valor que quieras persistir, recuperar o manipular programáticamente. Si no pasas Flag, muchos controles usan Name como fallback.

Documentation structure

La navegación es visual; el contenido es contractual. Cada página separa intención, firma, opciones, retorno, callback y gotchas.

Use a task path

Si quieres levantar una UI, ve a Quickstart. Si necesitas decidir qué control usar, ve a Components. Si depuras estado, ve a Runtime notes.

Read signatures before prose

Cada referencia muestra primero la firma exacta que el código expone, luego una explicación y una tabla de opciones. Esto reduce la ambigüedad al consultar una opción o comparar implementaciones.

Trust the generated index

El catálogo de iconos se genera directamente desde src/Icons/*/Icons.lua; no es una lista inventada ni una muestra incompleta.

Keep source links close

Los enlaces de cada sección apuntan al archivo o al contrato correspondiente, para que una corrección futura pueda contrastarse con la implementación.
