Carga uno o varios sets

El resolver descarga los catálogos desde el commit fijado en el runtime y los fusiona en iconMap.

Por defecto

Si no pasas IconSet, se intentan cargar los seis sets: lucide, gravity, craft, geist, sfsymbols y solar.

Un solo set

Usa un string para limitar la carga y reducir requests: IconSet = "lucide".

Varios sets

Usa un array. Se recorren en orden; cuando hay un nombre repetido, la primera definición permanece.

-- Desactivar la carga remota
local NoIcons = SynergyUI:CreateWindow({ IconSet = false })

-- Un solo catálogo
local Lucide = SynergyUI:CreateWindow({ IconSet = "lucide" })

-- Varios catálogos, orden de prioridad explícito
local Mixed = SynergyUI:CreateWindow({
  IconSet = { "solar", "lucide", "geist" },
})
Entorno HTTPLa carga necesita que el entorno pueda realizar request, syn.request, http.request, http_request o game:HttpGet. Si ninguno funciona, el resolver no añade nombres y los tabs siguen funcionando sin icono.

Usa un icono en un tab

El segundo argumento de CreateTab acepta un nombre resuelto, un string de asset explícito (rbxassetid://...), una URL HTTP o un descriptor de atlas. A diferencia de Window:SetBackground, CreateTab no normaliza strings numéricos a rbxassetid://.

-- Nombre resuelto desde IconSet
Window:CreateTab("Main", "home")

-- Asset directo
Window:CreateTab("Custom", "rbxassetid://3926305904")

-- También se acepta una URL http
Window:CreateTab("Remote", "https://example.com/icon.png")

Descriptor de spritesheet

Los catálogos como craft pueden devolver una tabla con Image, ImageRectPosition, ImageRectSize y opcionalmente Parts. CreateTab aplica automáticamente los rect offsets y tamaños disponibles.

local descriptor = {
  Image = "rbxassetid://123",
  ImageRectPosition = Vector2.new(96, 192),
  ImageRectSize = Vector2.new(96, 96),
}
-- Un descriptor custom también puede pasarse como icon.
Window:CreateTab("Atlas", descriptor)

Fallbacks & troubleshooting

El sistema es tolerante: la falta de un icono no impide crear el tab.

Icono no encontrado

Si una clave no existe, iconMap[name] or "" produce un tab sin imagen. Revisa spelling y el set que has cargado.

Nombre duplicado

El resolver no reemplaza un nombre ya registrado. Cambia el orden de IconSet si necesitas que otra fuente tenga prioridad.

Asset directo

Usa un string explícito como rbxassetid://ID o una URL HTTP. Los strings que contienen solo dígitos no se convierten automáticamente en CreateTab; esa normalización existe para Background y SetBackground.

Sin HTTP

Desactiva la expectativa de catálogo remoto con IconSet = false y pasa assets directos a tus tabs.
