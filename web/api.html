La superficie global es pequeña a propósito: crea ventanas, registra temas, traduce textos, emite notificaciones y abre diálogos. El estado detallado vive en la ventana y sus flags.

Localización · Theme API

SynergyUI:CreateWindow

La puerta de entrada al sistema. Devuelve una ventana viva y visible.

local Window = SynergyUI:CreateWindow(options) → Window

Si Theme no es un nombre registrado ni una tabla, se usa Dark. Si ToggleKey es el string "None", el atajo queda desactivado; los strings válidos se convierten a Enum.KeyCode. La ventana inicia visible, con título "Synergy Hub", tamaño 560 × 380 y configuración default_config.

Métodos de Window

Todos los métodos devuelven window cuando tiene sentido para encadenar.

Window:Open()Habilita el ScreenGui y dispara los hooks de apertura.

No hace nada si la ventana ya está abierta o destruida. Ejecuta primero la opción OnOpen y luego los callbacks registrados con OnOpen.

Window:Close()Cierra GUI y overlays asociados.

Oculta el ScreenGui, cierra todos los overlays y dispara OnClose más sus hooks. No destruye la ventana.

Window:Toggle()Alterna Open y Close.

Es la operación que invoca el ToggleKey. Respeta el estado destruido.

Window:IsOpen()→ boolean

Devuelve IsVisible and not Destroyed.

Window:Destroy()Libera conexiones, dialogs, overlays y GUI.

Es idempotente. Cierra primero si está visible, ejecuta callbacks de destrucción, limpia ConnectionBag, elimina la ventana del registro de localización y destruye el ScreenGui.

Window:SetToggleKey(keyName)Acepta nombre Enum o None.

Ejemplos: Window:SetToggleKey("F2") o Window:SetToggleKey("None"). La versión interna del control Flag = "Keybind" también actualiza este valor.

Window:SetTitle(value)Actualiza el título y su layout.

Soporta texto normal o una key de localización @Key.

Window:SetSubtitle(value)Crea, reemplaza o elimina el subtítulo.

Usa nil o una cadena vacía para eliminarlo.

Window:SetBackground(asset, transparency)→ boolean

Normaliza el asset ID. Si no es válido, elimina el fondo y devuelve false; de lo contrario devuelve true.

Window:SetAccent(color)Actualiza acento y refresca la ventana.

Sincroniza el borde, título, resize handle, scrollbar, indicadores de tab y el esquema semántico.

Window:SetTheme(themeValue)Acepta nombre registrado o tabla.

Clona y normaliza el tema, refresca todos los controles y persiste __theme si se proporcionó un nombre.

Window:RefreshTheme()Propaga colores a todos los controles vivos.

Úsalo después de mutar manualmente una tabla de tema o preferiblemente utiliza SetTheme/SetAccent. No devuelve un valor.

Window:RefreshLocalization()Recalcula textos localizados y el layout del título.

Fuerza una pasada de actualización sobre los objetos localizados y vuelve a medir el grupo de título de esta ventana. No cambia el idioma activo por sí sola y no devuelve un valor.

Window:SetLanguage(language)→ boolean

Delegación de SynergyUI:SetLanguage. Cambia el idioma global, actualiza todas las ventanas activas y devuelve true si el argumento es una cadena; en caso contrario devuelve false.

Window:Alert(options)→ Dialog

Abre un alert propiedad de la ventana. La implementación asigna OwnerWindow automáticamente.

Window:Confirm(options)→ Dialog

Abre un confirm propiedad de la ventana. La implementación asigna OwnerWindow automáticamente.

Window:Prompt(options)→ Dialog

Abre un prompt propiedad de la ventana. La implementación asigna OwnerWindow automáticamente.

Window:CreateTab(name, icon)→ elements

Crea sidebar button, scroll container y devuelve el namespace de constructores. El primer tab queda activo automáticamente. Consulta Componentes para todos los builders.

Hooks del ciclo de vida

Registra varios listeners sin reemplazar los callbacks de options.

Window
  :OnOpen(function(window) print("opened") end)
  :OnClose(function(window) print("closed") end)
  :OnDestroy(function(window) print("disposed") end)
Orden de eventosAl abrir: opción OnOpen, después listeners de Window:OnOpen; se repite en cada apertura real. Al cerrar ocurre lo mismo con Close. Al destruir, si está visible se cierra antes; luego se ejecuta el callback de destrucción y finalmente se limpian recursos.

Notificaciones

Feedback no bloqueante en cola y modal visual para decisiones simples.

SynergyUI:Notify

Acepta un string o una tabla. Las notificaciones se muestran una por una.

SynergyUI:Notify({
  Message = "Saved",
  Type = "done", -- info | done | error | warning
  Duration = 4.2,
  Position = "TopRight",
  TypeColor = Color3.fromRGB(0, 230, 100),
  Callback = function() end,
})

SynergyUI:CreateGameNotification

Modal animado con logo, título, descripción y dos acciones.

  NoText = "Later",

Diálogos

Tres contratos, un motor: Alert, Confirm y Prompt.

Alert

Un botón primario. Usa Callback(dialog).

Confirm

Confirmar/cancelar. Usa ConfirmCallback, CancelCallback y opcionalmente Callback(result, dialog).

Prompt

Incluye input. Callback(value, dialog); el botón Cancel entrega nil, mientras overlay/Escape entregan false.

local dialog = Window:Prompt({
  Title = "Project name",
  Content = "Type a name for the new project.",
  DefaultText = "demo",
  Placeholder = "my-project",
  ConfirmText = "Continue",
  CancelText = "Cancel",
  CloseOnOverlay = true,
  CloseOnEscape = true,
  Callback = function(value, dialog)
    if value then print(value) end
  end,
})
-- dialog.Input, dialog:Close(result), dialog:Destroy()
OpciónSignificado
TitleEncabezado; usa defaults localizados @Alert, @Confirm, @Prompt.
Content / DescriptionTexto envuelto del dialog.
AccentColor, BackgroundColorColores del borde/acento y tarjeta.
ConfirmText / OkText, CancelTextEtiquetas de acciones.
CloseOnOverlay, CloseOnEscapeAmbos true por defecto; controlan cierre sin acción explícita.
OwnerWindow, ParentLa llamada de ventana asigna OwnerWindow automáticamente; también puedes definir un padre.
