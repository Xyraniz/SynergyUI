Registra un tema custom

Registra una tabla, deja que el motor la normalice y aplica el nombre a cualquier ventana posterior.

SynergyUI:RegisterTheme("Aurora", {
  Colors = {
    Canvas = Color3.fromRGB(8, 12, 20),
    Surface1 = Color3.fromRGB(14, 23, 36),
    Surface2 = Color3.fromRGB(10, 18, 30),
    SurfaceHover = Color3.fromRGB(22, 38, 58),
    Border = Color3.fromRGB(44, 80, 112),
    TextPrimary = Color3.fromRGB(240, 248, 255),
    TextSecondary = Color3.fromRGB(160, 190, 212),
    Accent = Color3.fromRGB(88, 220, 255),
    AccentHover = Color3.fromRGB(130, 231, 255),
    AccentPressed = Color3.fromRGB(45, 160, 198),
  },
  Metrics = { Radius = 14, Padding = 16, Gap = 8, ControlHeight = 44 },
  Motion = { Fast = 0.10, Normal = 0.20, Window = 0.32 },
})

local names = SynergyUI:GetThemes() -- sorted names
local Aurora = SynergyUI:GetTheme("Aurora") -- cloned table
local Window = SynergyUI:CreateWindow({ Theme = "Aurora" })
Comportamiento de los clonesRegisterTheme almacena una copia normalizada y GetTheme devuelve otra copia. Puedes modificar el resultado sin mutar el registro global.

Cambia de tema en runtime

Elige entre cambiar todo el sistema visual o solo el color de acento.

Window:SetTheme

Acepta un string registrado o una tabla custom. Normaliza el valor, refresca tabs, controles, scrollbars y persiste __theme solo cuando se usa un nombre registrado.

Window:SetAccent

Cambia el accent semántico, borde, título, handle de resize, indicadores y referencias activas.

Window:RefreshTheme

Reaplica el tema actual. Úsalo después de mutar manualmente una tabla o, preferiblemente, utiliza SetTheme/SetAccent.
