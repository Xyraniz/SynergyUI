Config persistence

La configuración se guarda como JSON en el sistema de archivos del entorno cuando las funciones de filesystem están disponibles.

local Window = SynergyUI:CreateWindow({
  ConfigName = "profile_a",
})

-- Path used by the runtime:
-- SynergyUI/Settings/profile_a.json

Filesystem optionalSi isfolder, makefolder, isfile, readfile o writefile no están disponibles, la UI sigue funcionando, pero la persistencia no puede leer ni escribir.

Value priority

La restauración puede sorprender si el JSON contiene una clave del mismo nombre. Esta es la prioridad efectiva.

Saved flag

Para la mayoría de controles, si existe y tiene el tipo esperado, gana sobre todo lo demás. Dropdown valida además que el valor esté entre Options.

Current option

Si no hay valor guardado, se consulta la opción inicial específica del control: CurrentValue, CurrentOption, CurrentSelected, CurrentText o CurrentKeybind.

Component default

Por último, se usa el default: false para booleanos, primer option para dropdown/radio, primer valor del range para slider, None para keybind y 0 para NumberInput.

Excepción: RadioGroupCreateRadioGroup comprueba primero un CurrentValue válido y solo después consulta el valor guardado. Por tanto, en este control CurrentValue gana sobre el flag persistido; si ninguno es válido, se usa la primera opción.

Input behavior

La top bar arrastra la ventana. El handle lateral derecho inferior permite redimensionar. ToggleKey inicia en RightShift; mientras un Keybind está capturando, el toggle global se pausa.

Minimize is not closeMinimizar conserva la ventana y guarda __minimized. Cerrar deshabilita el ScreenGui. Destruir elimina el árbol completo y sus recursos.

Overlay manager

Dropdowns y otros overlays se posicionan respecto a un anchor, cierran al hacer click fuera y evitan solapamientos del mismo tipo.

Position

El overlay prefiere el espacio inferior; si no cabe, intenta arriba. X/Y se limitan al viewport con padding.

Exclusivity

Con Exclusive = true, CloseOthers cierra otros handles del mismo Kind.

Dismiss

Escape cierra todos. MouseButton1 o Touch fuera del overlay y fuera del anchor lo cierra si CloseOnOutsideClick está activo.

Behavior to account for

Detalles pequeños que conviene saber antes de diseñar una API encima de SynergyUI.

Initial callbacks

Toggle, CheckBox y Slider no disparan callback al crear salvo el caso explícito de toggle/checkbox true. Dropdown dispara si hay selección; RadioGroup no dispara por la selección inicial. Checklist sí ejecuta su callback durante la construcción inicial, incluso con una lista vacía.

Multi-select callbacks

Dropdown multi-select llama Callback(option, selected) en interacción, pero al restaurar puede invocarlo con el array completo.

Dynamic options

Dropdown puede añadir, quitar, limpiar y seleccionar opciones. Checklist solo añade y quita; no incluye ClearOptions ni Select.

Callbacks are protected

La mayoría se envuelve en pcall. Esto evita que un error de usuario rompa el loop visual, aunque conviene registrar el error dentro de tu callback.
