Antes de crear la primera ventana

SynergyUI se distribuye como un chunk Lua que devuelve la tabla SynergyUI. El flujo oficial descarga y ejecuta dist/main.lua con loadstring; no es un ModuleScript que debas cargar con require.

Loader oficialLa documentación utiliza la versión distribuida desde la rama main. Copia este bloque tal cual y conserva el resultado en una variable llamada SynergyUI. Para firmas completas y reglas de runtime, consulta llms.txt.
local SynergyUI = loadstring(game:HttpGet("https://raw.githubusercontent.com/Xyraniz/SynergyUI/main/dist/main.lua"))()

01 · Ejemplo básico

El contrato mínimo: ventana, tab y un botón. El callback se ejecuta al hacer click.

local Window = SynergyUI:CreateWindow({
  Title = "My first window",
})

local MainTab = Window:CreateTab("Main")

MainTab:CreateButton({
  Name = "Say hello",
  Callback = function()
    SynergyUI:Notify("Hello from SynergyUI")
  end,
})

Window

Se crea visible con tema Dark y tamaño 560 × 380.

Tab

El primer tab queda activo automáticamente y devuelve el namespace de elementos.

Button

Devuelve frame y connection; añade tooltip si lo necesitas.

02 · Ejemplo completo

Una base funcional para una UI con estado, preferencias persistentes y varios tipos de interacción.

local Window = SynergyUI:CreateWindow({
  Title = "Synergy Control",
  Subtitle = "preferences",
  Theme = "Slate",
  AccentColor = Color3.fromRGB(124, 157, 186),
  ToggleKey = Enum.KeyCode.RightShift,
  ConfigName = "synergy_preferences",
  IconSet = { "lucide", "solar" },
  OnDestroy = function() print("cleaned") end,
})

Window:OnOpen(function(window) print("opened") end)

local Main = Window:CreateTab("Main", "layout-dashboard")
Main:CreateSection("Runtime")
Main:CreateLabel("Changes are saved automatically.")

Main:CreateToggle({
  Name = "Enable feature",
  Flag = "FeatureEnabled",
  CurrentValue = true,
  Callback = function(value) print("enabled:", value) end,
})
local enabled = Window.Flags.FeatureEnabled

Main:CreateSlider({
  Name = "Strength",
  Flag = "Strength",
  Range = { 0, 100 },
  Increment = 5,
  CurrentValue = 50,
  Callback = function(value) print(value) end,
})
local strength = Window.Flags.Strength

local mode = Main:CreateDropdown({
  Name = "Mode",
  Flag = "Mode",
  Options = { "Safe", "Balanced", "Fast" },
  CurrentOption = "Balanced",
  Searchable = true,
  Callback = function(value) print(value) end,
})

local palette = Main:CreateColorPicker({
  Name = "Accent",
  Flag = "Accent",
  Color = Color3.fromRGB(88, 220, 255),
  Callback = function(color) Window:SetAccent(color) end,
})

local Settings = Window:CreateTab("Settings", "settings-2")
Settings:CreateKeybind({ Name = "Toggle UI", Flag = "Keybind", CurrentKeybind = "RightShift" })
Settings:CreateTextInput({ Name = "Profile", Flag = "Profile", Placeholder = "default" })
Settings:CreateButton({ Name = "Reset window", Callback = function() Window:SetTheme("Dark") end })

Estado

Cada flag se carga desde el JSON antes de usar CurrentValue. Los cambios llaman a ConfigHandler:Set y se guardan en diferido.

Iconos

Los nombres layout-dashboard y settings-2 se resuelven en los sets cargados. Usa varios sets cuando necesites cubrir familias distintas.

Callbacks

Los callbacks se invocan con pcall. Un error no debería desmontar el resto de la UI, pero debes registrar el error si quieres depurarlo.

Ciclo de vida de Window

Destroy limpia conexiones, tareas de rainbow, overlays y diálogos propiedad de la ventana.
