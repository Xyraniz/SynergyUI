Cada control
tiene un contrato.

Todos los builders viven en el objeto devuelto por Window:CreateTab. Cada control define su forma de entrada, su persistencia y el objeto que puedes conservar.

Matriz de controlesPatrón de Flag
elements namespace
local Settings = Window:CreateTab("Settings")
local sliderFrame, sliderConnections = Settings:CreateSlider({
  Name = "Volume",
  Flag = "Volume",
  Range = { 0, 100 },
})

local slider = Window.Flags.Volume
slider:SetValue(75)
local value = slider:GetValue()

Los flags son la capa de estado

Un flag es una clave estable en la configuración de la ventana y un objeto de control en Window.Flags.

local toggle = Tab:CreateToggle({
  Name = "Enabled",
  Flag = "Enabled",
  CurrentValue = false,
})

local current = toggle:GetValue()
toggle:SetValue(true)

-- La misma referencia queda disponible en la ventana:
local sameControl = Window.Flags.Enabled
Prioridad de valorCuando existe un valor guardado con el mismo flag y tiene el tipo esperado, el control lo usa primero. Si no, usa CurrentValue, CurrentOption, CurrentSelected, CurrentText o el default del componente.

Layout y contenido

Elementos sin flag para organizar contenido, separar secciones o mostrar medios.

elements:CreateSection(name)→ TextLabel de 28 px

Crea una cabecera de sección con color accent. Acepta textos localizados con prefijo @.

Tab:CreateSection("Advanced")
elements:CreateLabel(text)→ TextLabel

Tarjeta de texto simple con borde, accent lateral, wrapping y texto localizable.

Tab:CreateLabel("Changes apply instantly.")
elements:CreateSeparator()→ Frame de 1 px

Usa el color de stroke del tema para dividir grupos de controles.

elements:CreateParagraph(options)→ Frame auto-height

Opciones: Title, Content, Image y ImageDescription. La altura se calcula mediante TextService; la imagen mide 120 px.

Tab:CreateParagraph({
  Title = "About this profile",
  Content = "Longer explanatory text goes here.",
  Image = "rbxassetid://123456",
  ImageDescription = "Opciónal caption",
})
elements:CreateImage(options)→ acordeón de imagen

Opciones: Title, Image, Description. Comienza colapsado; al abrirlo muestra la imagen y una descripción opcional.

elements:CreateVideo(options)→ acordeón con Play/Pause

Opciones: Title, Video, Looped, Volume. El vídeo usa VideoFrame de Roblox y empieza pausado.

Inputs y bindings

Controles de texto, números y atajos, con validación mínima incorporada.

CreateTextInput

CurrentText y Placeholder. El callback recibe input.Text al perder foco. SetValue escribe directamente el texto.

CreateNumberInput

Filtra caracteres a dígitos, punto y signo. Al perder foco acepta solo valores convertibles con tonumber; si falla, restaura el valor anterior.

CreateKeybind

CurrentKeybind es un nombre string. Captura teclado y botones del mouse; Escape se guarda como None; una captura expira a los 5 segundos.

local Profile = Tab:CreateTextInput({
  Name = "Profile name", Flag = "Profile", CurrentText = "default",
  Placeholder = "Type a name",
  Callback = function(value) print(value) end,
})

local Amount = Tab:CreateNumberInput({
  Name = "Amount", Flag = "Amount", CurrentValue = 10,
  Callback = function(value) print(value) end,
})

local Hotkey = Tab:CreateKeybind({
  Name = "Action key", Flag = "ActionKey", CurrentKeybind = "F",
  Callback = function(value) print(value) end,
})

Controles booleanos y de elección

Usa Toggle para un estado binario, CheckBox para la misma semántica con otra presentación y RadioGroup para una selección única.

CreateToggle

state inicial booleano; callback recibe el nuevo estado. Al crear, solo llama callback si el estado inicial es true.

CreateCheckBox

Mismo contrato de estado que Toggle. El callback también recibe booleano y el flag expone GetValue/SetValue.

CreateRadioGroup

Options es obligatorio en la práctica. Selecciona la primera opción si no hay valor válido inicial. Nota: este control comprueba CurrentValue antes del valor guardado.

local Quality = Tab:CreateRadioGroup({
  Name = "Quality", Flag = "Quality",
  Options = { "Low", "Medium", "High" },
  CurrentValue = "High",
  Callback = function(value) print(value) end,
})

local checked = Tab:CreateCheckBox({
  Name = "Use cache", Flag = "UseCache", CurrentValue = true,
})

Controles numéricos

Slider es interactivo; ProgressBar representa un progreso pero también puede actualizarse por flag.

elements:CreateSlider(options)→ frame, connections

Requiere Range = { min, max }. Increment redondea por pasos durante drag, input numérico y SetValue. El callback recibe el número.

OpciónUso
CurrentValueValor inicial si no hay configuración guardada.
IncrementPaso de redondeo; default 1.
RangeArray de dos números; también se usa para limitar el rango.
elements:CreateProgressBar(options)→ objeto flag

Usa Range o Min/Max; si no se proporciona ninguno, el rango efectivo es 0–100. CurrentValue define el valor inicial cuando no existe persistencia. Expone GetValue, GetPercentage, SetValue y alias SetProgress. Format(current, ratio) puede personalizar el label; ShowPercentage muestra porcentaje redondeado y ShowValue = false oculta el texto del valor.

local slider = Tab:CreateSlider({
  Name = "Opacity", Flag = "Opacity", Range = { 0, 1 },
  Increment = 0.05, CurrentValue = 0.8,
  Callback = function(value) print(value) end,
})

local progress = Tab:CreateProgressBar({
  Name = "Download", Flag = "Download", Range = { 0, 100 },
  CurrentValue = 35, ShowPercentage = true,
  Format = function(current, ratio) return string.format("%d / 100", current) end,
})
progress:SetProgress(72)

Controles de selección

Dropdown sirve para una selección o varias; Checklist representa una lista expandible de selecciones múltiples.

elements:CreateDropdown(options)→ objeto flag, connection

Con MultiSelect = false, GetValue devuelve un string y el callback recibe el valor. En este modo, CurrentOption define la selección inicial cuando no existe un valor guardado válido. Con MultiSelect = true, GetValue devuelve un array y CurrentSelected define la selección inicial; al hacer click el callback recibe option, selected. Searchable añade filtro de texto.

local modes = Tab:CreateDropdown({
  Name = "Modes", Flag = "Modes",
  Options = { "Safe", "Fast", "Custom" },
  MultiSelect = true,
  CurrentSelected = { "Safe" },
  Searchable = true,
  Callback = function(option, selected) print(option, selected) end,
})
modes:AddOption("Experimental")
modes:RemoveOption("Safe")
modes:Select({ "Fast", "Custom" })
-- Esta llamada es opcional y limpia la lista completa:
modes:ClearOptions()
elements:CreateChecklist(options)→ objeto flag, connection

Opciones: Name, Flag, Options, CurrentSelected, Callback. GetValue devuelve un array; incluye AddOption y RemoveOption, pero no ClearOptions ni Select. La implementación también ejecuta el callback durante la construcción inicial y después de cada reconstrucción provocada por SetValue, AddOption o RemoveOption. Al expandirse limita la altura a 220 px.

Color y progreso visual

ColorPicker trabaja en HSV, serializa Color3 para persistencia y ofrece modo rainbow.

elements:CreateColorPicker(options)

Opciones: Name, Flag, Color, Callback. El callback recibe Color3. SetValue(newColor) detiene rainbow si estaba activo, actualiza hue/saturation/value y guarda el color.

local color = Tab:CreateColorPicker({
  Name = "Accent color", Flag = "AccentColor",
  Color = Color3.fromRGB(88, 220, 255),
  Callback = function(value) Window:SetAccent(value) end,
})
color:SetValue(Color3.fromRGB(165, 139, 255))
-- El botón del control alterna entre Rainbow y Stop.
Persistencia de Color3La configuración guarda { __type = "Color3", r = color.R, g = color.G, b = color.B }. No reemplaces esta forma al editar el archivo manualmente.

Detalles de Button

El botón es el control sin estado y el único builder que devuelve su frame junto a la conexión del evento.

local frame, connection = Tab:CreateButton({
  Name = "Export",
  Tooltip = "Write the current profile to disk",
  Callback = function()
    SynergyUI:Notify({ Message = "Exported", Type = "done" })
  end,
})

Añade hover, escala ligera y ripple en la posición del click. Si el callback lanza un error, SynergyUI muestra una notificación de tipo error.
